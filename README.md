# 과제 04 - 이진트리 순회

괄호로 입력한 이진트리를 만들고, 재귀 없이 스택으로 전위/중위/후위 순회를 합니다.

## 입력 방법

```
A(B(D,E),C(,F))
```

- `노드(왼쪽,오른쪽)` 로 씁니다.
- 자식이 없으면 비워 둡니다. 예: `C(,F)`
- 빈 줄이나 `q` 를 입력하면 끝납니다.

## 구현 방법

- 노드는 데이터, 왼쪽 포인터, 오른쪽 포인터를 가집니다.
- 세 순회 모두 재귀 없이 스택과 반복문을 사용했습니다.
  - **전위**: 꺼낸 노드를 출력하고, 오른쪽 → 왼쪽 순서로 스택에 넣습니다.
  - **중위**: 왼쪽 끝까지 넣고, 꺼내서 출력한 뒤 오른쪽으로 갑니다.
  - **후위**: 오른쪽을 이미 방문했는지 `last` 로 확인하고, 방문했으면 출력합니다.
- 괄호가 맞지 않는 등 잘못된 입력은 오류 메시지를 출력합니다.
